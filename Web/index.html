LOCAL CHAT BACKUP

别让重要对话，突然消失。

GPT 对话保险箱会自动备份 ChatGPT 页面中已经显示的内容。遇到页面刷新、历史列表异常、长对话丢失或多设备使用记录不稳定时，你仍然可以从本机找回关键内容。

查看功能 隐私政策

每个人都应该有一份自己的本地记录。

01 / AUTO

自动保存

打开 ChatGPT 对话页后，插件会自动捕捉页面中已经显示的用户消息和 GPT 回复。

02 / LOCAL

只存在本机

备份保存在浏览器本地 IndexedDB 中，不上传服务器，不共享给第三方。

03 / EXPORT

一键导出

支持将单条对话或全部备份导出为 Markdown / JSON，方便归档和迁移。

适合这些场景

它不是替代 ChatGPT 官方历史记录，而是给你多一层本地保险。

  • 长对话进行到一半，页面突然刷新或崩溃。
  • 历史列表加载异常，临时找不到刚才的对话。
  • 多人、多设备协作时，每个人都希望保留自己的关键记录。
  • 重要方案、代码、提示词需要导出为 Markdown 做归档。
  • 希望数据尽量保留在本机，不依赖额外云同步。

边界也说清楚

  • 只能备份浏览器页面里已经显示出来的内容。
  • 不能恢复 OpenAI 服务器侧已经删除或未加载出来的历史记录。
  • 第一版主要保存文字和代码块，不重点保存图片、附件和语音。
  • 卸载扩展或清理浏览器扩展数据，可能会删除本地备份。
